# 인구·동네 — 광고 없는 우리 동네 인구 통계

행정안전부 주민등록 인구통계를 **법정동(읍·면) 단위까지** 그대로 보여 주는 정적 사이트.
Cloudflare Worker 한 개로 돌아가고, 광고·추적·외부 스크립트가 **0개**다.

만든 이유는 단순하다. 같은 공공데이터를 보여 주는 사이트가 이미 있는데
광고가 화면을 덮어 숫자를 읽기가 불편했다. 자료는 공공누리 제1유형이라 누구나 쓸 수 있으니,
같은 내용을 광고 없이 다시 만들었다.

## 무엇을 보여 주나

읍·면·동 한 곳마다 한 페이지:

| 구획 | 내용 |
|---|---|
| 요약 한 줄 | 수치를 읽어 이 동네의 특징을 문장으로. "유소년이 11.9%로 전국(10.1%)보다 많습니다…" |
| 지표 카드 | 총인구·평균연령·세대수·1인 세대. 각 카드에 시군구·전국 값을 함께 |
| 기준 대비 위치 | 지표 다섯 개를 **같은 시군구 동네들의 분포 위에** 올리고, 시군구·시도·전국 평균을 눈금으로 |
| 연령 | 10세 구간 남녀 피라미드 + **시군구 평균 분포를 점선으로 덧그림** |
| 연령 구성 | 유소년(0~14)·생산연령(15~64)·고령(65+), 바로 아래 전국 견줌 막대 |
| 세대 | 1인~5인 이상 세대 구성, 세대당 인구, 전국 비중 대조 |
| 시군구 안에서 | 인구 순위 그래프 + 동네·시군구·시도·전국 4단 비교표 |
| 인구 변화 | 같은 달 기준 연도별 추이와 전년 대비 증감 |
| 그 밖 | 읍·면이면 법정리 목록, 공유 카드, FAQ, 자료 출처 |

시도·시군구 페이지, 이름 검색, JSON API 도 같은 자료로 돈다.

### 숫자에 맥락을 붙이는 방법

45.3세가 많은 건지 적은 건지는 다른 숫자를 알아야 판단된다. 그래서 지표마다
게이지를 하나씩 둔다.

```
평균연령                   중구 43.1세 · 대구 46.8세 · 전국 46.2세
                45.3세
  ▁▁▁▁▁▁▁▁●▁│▁│▁▁▁▁▏▏▏▏ ▏ ▏▏  ▏  ▏    ▏      ▏
            중구 전국·대구
```

- 가로줄의 범위 = 같은 시군구 안 읍면동들이 퍼져 있는 구간(위아래 5% 절단)
- 옅은 세로선(rug) = 그 동네들 하나하나
- 굵은 세로 눈금 = 시군구·시도·전국 평균
- 동그라미 = 이 동네

극단값 한 곳이 축을 늘려 기준선 셋이 한 점에 뭉치는 일을 막으려고 5~95 퍼센타일로
자른다. 기준선이 가까이 붙으면 이름을 묶어(`중구·전국`) 한 번만 적는다.

### 두 동네 견주기

```
/vs/남산동/대봉동          이름만
/vs/중구 남산동/대봉동      이름이 겹치면 시군구를 앞에
```

마주 보는 막대로 지표를 견주고, 인구 피라미드를 **서로 겹쳐** 그린다(상대의 분포를
같은 인구로 환산해 점선으로). 어느 나이대가 다른지 한눈에 보인다.
한쪽 이름이 여러 곳이면 후보를 보여 주되 **반대쪽을 주소에 그대로 들고 간다** —
그냥 동네 페이지로 보내 버리면 방금 고른 비교 대상이 사라지기 때문이다.

### 공유 카드

- `/og/{법정동코드}.svg` — 1200×630 카드를 워커가 그때그때 그린다
- `/og/{법정동코드}.png` — 미리 구워 KV 에 올려 둔 것이 있으면 그걸, 없으면 위 SVG 로 넘김
- `/{시도}/{시군구}/{동}?card` — 캡처용 화면(카드 한 장만)

`og:image` 는 `.png` 를 가리킨다. **SVG 를 og:image 로 받아 주지 않는 서비스가 많아서
(카카오톡 포함), 미리 구운 곳만 링크 미리보기에 그림이 뜬다.** 굽는 방법:

```bash
node region/scripts/make-og.mjs --top 300   # 인구 상위 300곳 (KV 쓰기 300회)
bash region/scripts/kv-upload.sh
```

전국 5천 곳을 다 굽지 않는 이유는 KV 무료 쓰기 한도(1,000회/일) 때문이다.
굽지 않은 곳도 카드 자체는 `/og/….svg` 로 항상 볼 수 있다.

## 주소가 짧다

원본 격인 사이트의 주소는 `/region/Daegu/Jung-gu/Namsan-dong` 처럼 로마자로 길다.
여기서는 한글 그대로 쓰고, 앞을 생략할 수 있게 했다.

```
/대구/중구/남산동      정식 주소
/중구/남산동           시도 생략 (전국에서 유일하면 301)
/남산동                시군구까지 생략 (겹치면 후보 목록)
/c/g52bw               가장 짧은 공유용 (법정동코드 36진수, 5글자)
/2711015600            법정동코드 그대로
/api/대구/중구/남산동   같은 규칙의 JSON
```

한글 주소는 복사하면 퍼센트 인코딩으로 45자가 넘어간다. 그래서 페이지마다
`/c/…` 짧은 주소와 복사 버튼을 둔다.

## 자료

- 출처: **행정안전부 주민등록 인구통계** (<https://jumin.mois.go.kr>) — 공공누리 제1유형
- 단위: 법정동. 읍·면 지역은 원자료가 **리 단위로만** 오므로 리를 읍·면으로 합산한다
  (평균연령은 인구 가중평균).
- 갱신: 매월. 사이트가 들고 있는 최신 월을 스크립트가 자동으로 찾는다.
- 추이: 법정동 기준 통계는 2023년부터 있다. 그 이전 연도를 요청하면 오류 대신
  '전부 0' 인 CSV 가 오므로, 조회 가능 연도를 먼저 확인해 그 범위만 받는다.

## 구성

```
region/
├── scripts/
│   ├── jumin.mjs          행안부 사이트 내려받기 공통부 (TLS 1.2 고정 · CP949 디코딩)
│   ├── fetch-jumin.mjs    원천 CSV → data/raw/   (이미 받은 달은 건너뜀)
│   ├── build-data.mjs     CSV → worker/index.js + data/kv/*   (집계·검산·색인)
│   ├── test-routes.mjs    주소 규칙 + 숫자 정합성 + 극단값 렌더 + '광고 없음' 검사
│   ├── make-og.mjs        공유 카드 PNG 미리 굽기 (선택)
│   ├── preview.mjs        배포 없이 로컬에서 워커 그대로 띄우기
│   ├── kv-upload.sh       data/kv-bulk.json → Cloudflare KV
│   └── deploy.sh          내려받기 → 빌드 → 점검 → KV → 배포
├── worker/
│   ├── worker.js          라우팅·짧은주소·견주기·공유카드·API·sitemap
│   ├── render.js          페이지 HTML
│   ├── insight.js         지표 계산 · 요약 문장 · 기준선 게이지 값
│   ├── chart.js           SVG 그래프(서버에서 그림)
│   ├── ogcard.js          공유 카드 1200×630 SVG
│   ├── style.js           CSS 전량 인라인
│   ├── code.js            법정동코드 ↔ 짧은 주소
│   ├── index.js           시도·시군구 목록 + 전국 기준값 (build-data.mjs 가 생성)
│   └── wrangler.toml
└── data/                  생성물 — git 에 넣지 않는다 (원천 CSV 약 18MB)
```

### 왜 KV 로 쪼갰나

읍·면·동 전수 자료는 2MB 남짓이라 워커 번들에 넣기 어렵다.
반면 페이지 한 장에 필요한 건 **그 동네가 속한 시군구 하나**뿐이고,
그 안에 형제 동네가 다 들어 있어 순위·평균비교·이웃목록까지 한 번에 그릴 수 있다.
그래서 시군구 단위로 쪼개 KV 에 두고, 상세 페이지 = **KV 읽기 1회**로 끝낸다.
시도·시군구 목록만 번들(`index.js`, 30KB)에 남겨 대부분의 요청은 KV 조회조차 없다.

## 돌려보기

```bash
node region/scripts/fetch-jumin.mjs      # 원천 CSV 내려받기 (최초 약 18MB)
node region/scripts/build-data.mjs       # 집계 → worker/index.js, data/kv/
node region/scripts/test-routes.mjs      # 810개 점검 (주소·합계·극단값·광고없음)
node region/scripts/preview.mjs          # http://localhost:8788
```

`preview.mjs` 는 KV 를 로컬 파일로, 엣지 캐시를 no-op 으로 갈아 끼우고
`worker.js` 를 **그대로** 부른다. 배포본과 코드가 한 벌이라 "로컬은 되는데 배포는 안 됨"이 없다.
`--dump` 를 주면 서버 없이 HTML 만 뽑는다:

```bash
node region/scripts/preview.mjs --dump "/대구/중구/남산동" > out.html
```

## 배포

```bash
npx wrangler login
cd region/worker && npx wrangler kv namespace create REGION   # 출력 id 를 wrangler.toml 에 기입
bash region/scripts/deploy.sh
```

매월 통계가 갱신되면 자료만 올리면 된다(코드가 그대로면 재배포 불필요):

```bash
bash region/scripts/deploy.sh data
```

단, **행정구역 자체가 바뀐 달**(시군구 신설·통합)에는 시도·시군구 목록이 번들에 있으므로
`deploy.sh` 전체를 돌려 재배포해야 한다.

## 광고가 없다는 걸 어떻게 보장하나

- 페이지에 외부 호스트를 가리키는 태그가 하나도 없다. `test-routes.mjs` 가 매번 검사한다.
- 응답 헤더에 `Content-Security-Policy: default-src 'none'` 을 박아 두어,
  누가 나중에 스크립트를 끼워 넣어도 브라우저가 차단한다.
- 이미지·웹폰트·iframe 도 쓰지 않는다. 그래프는 서버에서 SVG 로 그린다.
  요청 수는 HTML 한 개다.

## 화면 설계 메모

- **2단 격자** — 980px 이상에서 두 단. 카드는 `align-items:start` 라 각자 제 높이만 쓴다.
- **그래프 폭은 540px 로 묶는다.** viewBox 는 400 폭 기준이라 카드 폭만큼 늘리면
  글자만 부풀어 촌스러워진다. 한 번 그렇게 나온 뒤로 상한을 뒀다.
- **숫자는 tabular-nums.** 표에서 자릿수가 흔들리지 않는다.
- **글꼴은 기기에 있는 것만.** 웹폰트를 쓰면 외부 요청 0개가 깨진다.
- **인쇄 스타일 있음.** 머리말·검색창·공유 상자를 숨기고 카드가 페이지 사이에서
  잘리지 않게 한다.

## 알려진 한계

- **행정동은 다루지 않는다.** 이 사이트는 법정동 기준이다("남산동"은 법정동이고,
  행정동 남산1~4동으로 나뉜다). 법정동↔행정동 매핑은 이 통계에 들어 있지 않아
  별도 자료가 필요하다.
- 법정리는 읍·면 페이지 안에 목록으로만 나오고, 리 단위 페이지는 없다.
- 인구 0인 법정동(공부상만 남은 곳)은 목록에서 뺀다.
