# 검색 품질 루프 리포트 (질문 50개 / 루프 10회)

> **목적** — 실무 질문을 던져 → 검색 결과(답변 근거)를 보고 → 문제 여부를 판정하고 →
> 수정안을 제안하는 루프를 10회 반복한 기록. **이 문서는 진단·제안까지만** 담는다.
> 실제 코드 수정은 별도 세션에서 내용 확인 후 진행한다.
>
> - 검증 경로: `retrieve(index, q, 7, ["법령","행정규칙"]) → expandReferences(...)`
>   — `worker.js` 배포 경로와 동일(단, 로컬엔 KV 벡터가 없어 BM25 단독. 하이브리드는
>   BM25 상위 20 안에서만 재순위하므로 **BM25가 놓친 조문은 배포본도 놓친다**).
> - 인덱스: `build-index.mjs` 재생성 기준 **4,277 청크**.
> - 판정: ✅ 정상 / ⚠️ 부분 문제(정답이 상위에 있으나 노이즈·순위 문제) / ❌ 실패(정답 조문 미검색)

## 루프 1 — 조합설립·사업시행·해제·임원

| # | 질문 | 판정 |
|---|---|---|
| 1 | 재개발조합 설립인가 동의율 | ⚠️ |
| 2 | 사업시행계획인가 전 총회 동의 비율 | ❌ |
| 3 | 분양신청 안 한 조합원 손실보상 협의 기한 | ⚠️ |
| 4 | 정비구역 지정 해제 사유 | ❌ |

**Q1** — 정답은 도정법 제35조②(재개발: 토지등소유자 3/4 + 토지면적 1/2). 실제 1·2위는
**빈집법 시행령 제20조·빈집법 제23조**(가로주택 4분의3), 도정법 제35조는 5위.
`소규모재개발사업`이 `재개발`을 부분문자열로 포함해 빈집법이 끌려온다. → **P3**

**Q2** — 정답은 도정법 **제45조④**(조합원 과반수 찬성, 사업비 10% 이상 증가 시 2/3)와
**제45조⑩**(직접출석 20%). 제45조가 **7위 안에 아예 없음**. 제50조⑤는 "총회의 의결을
거쳐야"라고만 하고 조문번호를 안 써서 `expandReferences`도 못 따라간다. → **P5**

**Q3** — 도정법 제73조(관리처분 인가·고시 다음 날부터 90일)가 2위, 1위는 빈집법 제36조
(사업시행계획 인가·고시일부터 90일). **기산점이 다른 두 법**이 섞여 오인용 위험. → **P3**

**Q4** — 정답은 도정법 **제20조(정비구역등의 해제)·제21조(직권해제)**. 7위까지 전부
`제101조의8 정비구역 지정의 특례`의 호 단위 조각. 원인 두 가지:
- `해제되는`이 조사 목록의 `는`에 먼저 걸려 **`해제되`**로 잘림 → `해제`가 검색어에 없음(**P1**)
- `정비구역 지정의 특례`의 **`지정의`가 `/정의/`에 오탐** → 호 단위로 쪼개지고 정의 가중
  (×1.5)까지 받아, 36~50자짜리 조각이 BM25 길이정규화로 상위 독식(**P2**)

**Q5** — 제41조(임원)·시행령 제40조(임원 수) 정상.

### 수정 제안 (루프 1)
1. `retrieve.mjs` JOSA 배열을 **길이 내림차순 정렬 후** 매칭(또는 후보 중 최장 접미사 선택).
   `const JOSA_SORTED = [...JOSA].sort((a,b)=>b.length-a.length)`.
2. `build-index.mjs`·`retrieve.mjs`의 정의 판정을 `/정의/` → **`/^정의$|용어의 정의|의 정의$/`**
   로 좁힌다. (`지정의`·`규정의`·`결정의`·`선정의`·`산정의`·`조정의` 오탐 차단)
3. `domainPenalty`에 **소규모주택정비법 계열 감점** 추가:
   `SMALL_LAW = /^빈집 및 소규모주택/`, `SMALL_INTENT = /빈집|가로주택|소규모재건축|소규모재개발|자율주택|소규모주택정비/`.
   (도정법·노후법과 같은 방식. 단, `재개발`·`재건축` 단독 신호로는 켜지지 않게 할 것)
4. 총회 정족수 질의 보강 — `SYN`에 `총회동의→총회 의결 정족수 찬성`, 또는
   `expandReferences`에 "조문번호 없는 절차 참조"용 고정 매핑(인가 조문 → 제45조) 검토.

   규칙 4·7이 이미 처리한다.
2. `expandReferences` 트리거에서 `이상` 앞에 **숫자·비율 표현(`100분의`, `\d+분의`, `\d+%`,

`제53조 시행규정의 작성` 호 조각은 **`규정의`가 `/정의/`에 오탐**된 결과. → **P2**

**Q15** — 조특법 제104조의7 1위. 정상.

### 수정 제안 (루프 3)
1. **세법 앵커 보정** — 질의에 정비 신호(`정비사업|재개발|재건축|조합`)가 있으면, 세법 청크
   중 본문에 `도시 및 주거환경정비법|정비사업|재개발|재건축`을 포함한 조문에 가산점(×1.5~2).
   반대로 정비 신호가 있는데 이 표현이 전혀 없는 세법 조문은 추가 감점.
2. `취득세 감면` 류 **광범위 질의는 근거 부족으로 판정**되게 — 최고점이 임계값 미만이면
   `NO_EVIDENCE`로 돌리는 하한선(예: 상위 1위 score < 25) 검토. 지금은 무관 조문이라도
   무조건 7개를 프롬프트에 넣어 LLM이 억지 인용할 여지를 준다.
3. corpus 보강 후보: 소득세법 시행령(제154·155·156조의2), 지방세법 제9조(신탁재산 비과세).

**그 차이를 쓰는 로직이 없다.** `pipeline.generate()` 는 `hits.length` 만 보고
`NO_EVIDENCE` 를 판단하므로, 사실상 **거절 경로가 작동하지 않는다.**

**Q50** — 분양자격은 도정법 제76조 + **시도조례** 사항인데, 지역 미지정이라 조례가

### 수정 제안 (루프 10)
1. **점수 하한선** — 상위 1위 점수가 임계값(예: 25) 미만이면 조문을 넣지 않고
   `NO_EVIDENCE` 반환. 임계값은 이번 50문항 점수 분포로 캘리브레이션 가능
   (정상 질의 1위: 30~85 / 무근거 질의 1위: 18~26).
2. 또는 프롬프트에 "상대 점수가 낮은 참고자료" 표시를 붙여 LLM이 거절하기 쉽게 한다.
   (1안이 결정론적이라 우선)
